# Фото ИИ — Telegram Mini App

## Что реализовано
- Загрузка JPG, PNG и WEBP до 12 МБ.
- Поле для описания изменений и быстрые подсказки.
- Регулировка силы перерисовки и размера результата.
- Запрос image-to-image в AI Horde с анонимным ключом `0000000000` — регистрация не требуется.
- Ожидание завершения задачи, просмотр результата, открытие и попытка скачать изображение.
- Адаптивный интерфейс для Telegram Web App и мобильного браузера.

## Важные ограничения
- AI Horde — общественная очередь вычислений; анонимные запросы имеют низший приоритет. Время обработки и доступность не гарантируются.
- Image-to-image перерисовывает изображение и может менять детали оригинала.
- Изображение передаётся стороннему сервису. Не загружайте конфиденциальные фотографии.
- Приложение размещено на GitHub Pages, поэтому секретные ключи провайдеров хранить здесь нельзя. Cloudflare Workers AI и другие API, требующие аккаунт/ключ, не подключены.
- Проверка CI подтверждает структуру и синтаксис, но не гарантирует доступность стороннего API, CORS, очередь или работу скачивания внутри конкретной версии Telegram. Для полноценной надёжности нужен реальный тест на устройстве.

## Публикация
После слияния изменений в `main` GitHub Actions развернёт сайт автоматически:
https://bizon77791-tech.github.io/english-daily/

Если Telegram показывает старую версию, измените параметр версии в Menu Button BotFather, например на `?v=photo1`. Настройку BotFather нельзя выполнить через GitHub; это отдельная настройка Telegram-бота.
