1. Исходная фотография

Редактирование выполняется официальной моделью GPT Image через OpenAI API. Для работы нужен отдельный API-ключ и оплачиваемый API-баланс: подписка ChatGPT не включает API-запросы. Ключ используется только в текущей открытой странице и не сохраняется приложением. Не используй это приложение на чужом устройстве и не публикуй свой ключ. Фотография отправляется в OpenAI для обработки.

Создать ключ можно в OpenAI API keys. Нужен активный API-доступ и баланс. Не вставляй сюда пароль от ChatGPT.

3. Результат

Результат готов.

На Android сохранение может открыться как загрузка браузера. Если Telegram не сохраняет файл напрямую, открой изображение отдельно и выбери «Скачать» или «Сохранить изображение».

Как добиться точного результата

Пиши конкретно: что изменить и что строго оставить без изменений. Например: «Замени только фон на белый. Сам товар, его форма, цвет, логотип, пропорции и ракурс должны остаться неизменными. Не добавляй предметы и текст».

Это приложение использует модель редактирования GPT Image, а не свободную модель перерисовки. Но генеративное редактирование всё равно не гарантирует сохранение каждого пикселя. Для защиты важных деталей лучше формулировать запрос на локальное изменение и использовать маску (поддержка маски пока не добавлена).
